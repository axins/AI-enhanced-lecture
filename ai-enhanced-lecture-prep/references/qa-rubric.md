# 质检清单、验收门槛与失败模式

---

## 一、机械校验（`qa_lecture.py` 自动完成）

| 检查项 | 判定标准 | 失败处理 |
|---|---|---|
| 页序覆盖 | 缺页列表为空 | 补齐缺页 |
| 重复页 | 重复列表为空 | 合并或重编号 |
| 页号顺序 | 严格递增 | 重排 |
| 页数一致 | 与课件页数相同 | 核对基线 |
| 维度计数 | 六类维度均 ≥1 | 补最弱的维度 |
| 维度均衡 | 无某类占比 >60% | 拆分或归并 |
| 空白页 | 均显式标注 | 补处理建议 |
| 标记词 | 数量归零或逐条有结论 | 走 P4 核查流程 |

## 二、人工校验清单

每讲交付前逐项打勾：

**内容质量**

- [ ] 每页【讲稿要点】是**判断句**，而非页面内容的复述
- [ ] 每页至少 3 条实质性补充
- [ ] ◤互动◢ **每一条都有参考答案或引路要点**
- [ ] ◤人物◢ 给出了代表作与学派归属；易混人名已辨析
- [ ] ◤文献◢ 给出了完整出处（作者、篇名、期刊/出版社、卷期、页码、年份）
- [ ] ◤实践◢ 涉及现行制度与数据时注明了时效
- [ ] 涉及价值分歧的议题用**分析框架**处理，未作单向宣判

**结构质量**

- [ ] 全讲至少 3 条跨讲交叉引用，且写明"回接 第 N 讲 第 x 页"
- [ ] 核心条目（出现 ≥2 次的理论/人物/研究）均已补三子块
- [ ] 文件头体例说明齐全
- [ ] 文件尾两附录已写（最需修改处、实证题目）

**可核验性**

- [ ] 所有链接带类型标签与访问日期
- [ ] 无凭记忆写出的卷期、条号、人名、数据
- [ ] 链接存活性校验通过
- [ ] 存疑条目已写「未检索到权威来源，建议课堂上不引用」

**一致性**

- [ ] 人名拼写全课程统一
- [ ] 术语译名统一
- [ ] 作业要求与大纲一致（字数、材料项数、评分条目、汇报时长）
- [ ] 评分标准分数合计正确
- [ ] 跨讲重复内容均有明确分工

## 三、常见失败模式

按代价从高到低排列。前六种最常见，且代价最高。

### 1. 一次性生成整册

**表现**：要求"把这 100 页全部扩展完"，输出前半部分质量尚可，后半部分明显变薄、缺页、重复。
**原因**：上下文衰减与输出长度限制。
**对策**：分批推进（每批 10—15 页或按章节），每批完成即校验。

### 2. 不标「需核实」

**表现**：AI 对不确定的条目直接给出看似确定的表述，错误静默进入讲稿。
**对策**：强制要求"无法确认即写标记词"；用 `extract_todo.py` 统计标记数，数量异常低反而是危险信号。

### 3. 凭记忆写文献卷期与条号

**表现**：讲稿中充满具体的卷期页码与条号，但相当比例是错的。
**代价**：最高。学术可信度一旦受损难以恢复，且学生可能在课堂上当场查证。
**对策**：所有卷期、条号、DOI 必须来自实际检索；检索不到就写"未检索到权威来源"。

### 4. 未做跨讲一致性检查

**表现**：同一门课的课件第 7 页说 5 项评分、第 52 页说 4 项、第 31 页说 4 项且总分只加到 80 分，大纲又是另一套。
**代价**：学生一定会发现并提问。
**对策**：P6 阶段用 AI 做全局一致性审计（AI 在此类字符串比对上远胜人工）。

### 5. 平行讲次重复却不分工

**表现**：同一案例/理论在两讲中完整讲了两遍。
**对策**：重复审计 + 分工表；若确需重复（如作为理论应用），必须**换角度**并在开场明确说明。

### 6. 只补内容不加交叉引用

**表现**：每讲独立充实，但课程缺乏整体感，期末无法复习。
**对策**：强制每讲 ≥3 条跨讲引用；在每讲小结页做"本讲 × 前 N 讲"对照表。

### 7. 链接堆砌无分类

**表现**：补了大量链接但不标类型与访问日期，学生无法判断可信度。
**对策**：五类标签 + 访问日期；`check_links.py` 定期复检。

### 8. 讨论题没有参考答案

**表现**：◤互动◢ 只写"提问：……"，课堂上讨论发散、无法收束。
**对策**：每条互动必附"引路要点"（不是标准答案，而是防止跑偏的抓手）。

### 9. 空白页静默跳过

**表现**：连续多页图片页/空白页在讲稿中被跳过，课堂上教师自己也不记得那里该放什么。
**对策**：空白页必须显式标注并给处理建议（保留/删减/替换）。

### 10. 扩展建立在未核查的错误上

**表现**：先做深度扩展，后做事实核查，导致扩展内容围绕错误前提展开，大量返工。
**对策**：核查优先于扩展（原则 3）。

## 四、质量信号

正向信号（可放心推进）：

- 标记词数量在扩展阶段上升、在核查阶段归零
- 交叉引用数量随讲次推进而增加
- 每讲字数与维度计数分布大致均衡

危险信号（应暂停并检查）：

- 标记词数为 0 却包含大量具体卷期与条号 → 极可能凭记忆编造
- 后半部分页的平均补充条数显著低于前半部分 → 批量生成塌方
- 链接总数很高但类型标签很少 → 可能是堆砌
- 某讲无任何跨讲引用 → 该讲与课程脱节
