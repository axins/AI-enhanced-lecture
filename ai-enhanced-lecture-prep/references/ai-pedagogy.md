# 课堂侧：AI 增强教学活动与作业规范

本文件说明在**教学环节**（课堂上与学生作业中）如何设计 AI 增强方案。核心判断：

> 目的不是用 AI 给出标准答案，而是让学生看见自己的思考过程，并学会审计机器的回答。

---

## 一、核心方法：三回答对照法

适用于开放式讨论题，每次约 35—40 分钟，一学期安排 5—8 次。

### 流程

| 步骤 | 时长 | 内容 |
|---|---|---|
| 1. 提前公布问题 | 课前 | 学生可预习，但**不得预先求助 AI** |
| 2. 独立作答 | 5 分钟 | 不看资料，写下三部分：①你的结论；②理由与所依据的理论；③你在哪些地方不确定、需要什么信息才能判断 |
| 3. AI 作答 | 5 分钟 | 教师给出**统一提示词**，全班获得可比较的回答；或学生各自生成后提交，教师投屏若干典型回答 |
| 4. 差异对照 | 10 分钟 | 按统一对照表逐项比较（见下） |
| 5. 反向核查 | 8 分钟 | 对 AI 回答做事实核查与引用核查，找出错误、幻觉、过时规则与不存在的案例 |
| 6. 反思写作 | 课后 200 字 | 我漏掉了什么？AI 漏掉了什么？我的判断是否改变？为什么？ |

### 统一对照表（第 4 步使用）

| 对照项 | 我的回答 | AI 的回答 | 差异说明 |
|---|---|---|---|
| 结论 | | | |
| 主要理由 | | | |
| 依据的理论/材料 | | | |
| 考虑到的情境与约束 | | | |
| 未考虑到的群体或立场 | | | |
| 不确定的地方 | | | |

### 统一提示词模板

```
你是本课程的讨论助手。请就以下问题作答：
①明确给出你的结论；
②列出三条理由，并注明各自依据的理论或经验材料；
③说明你最不确定的地方；
④指出你的回答最可能忽略的视角或群体的立场。

问题：【　　】
```

学生可微调提示词，但须在提交材料中记录改了什么。

### 评分要点

**不评价"谁的答案更对"**，而评价：

- 差异识别的准确度
- 对 AI 错误与幻觉的发现
- 反思的深度与诚实度

计入课堂讨论成绩。

### 设计要点

- **第 2 步是灵魂**。学生写下的"不确定之处"是最有价值的产出：它让"知道自己不知道什么"成为可训练、可评价的能力
- **统一提示词**保证回答可比较；否则各人提示词不同，对照失去意义
- **教师可预设观察点**：AI 通常能给出结论，但很少先界定概念与判断标准——这个差异是最好的教学材料

## 二、其他 AI 增强课堂活动

可按需选用，均约 15—30 分钟：

| 活动 | 做法 | 训练什么 |
|---|---|---|
| **AI 多角色论证** | 让 AI 分别扮演争议中的不同角色与不同学科视角，学生比较各份论证的说服力与盲点 | 视角转换、论证评估 |
| **AI 质证练习** | 学生连续追问 AI 回答的依据、数据来源与推理链条 | 可解释性追问能力 |
| **人机辩论** | AI 持一方立场、学生持另一方；赛后复盘 AI 论证中的漏洞与修辞技巧 | 论证识别、修辞警觉 |
| **AI 幻觉审计竞赛** | 给定 AI 生成的材料摘要或检索结果，比赛谁找出的编造内容、错误引用最多 | 事实核查、引用规范 |
| **AI 预测对照** | 用 AI 预测课堂未讲过的案例结果，再与真实结果对照 | 预测与解释的区别、一致性问题 |
| **课堂算法审计** | 小组对某一平台的推荐、排序或评分规则做黑箱审计，记录规则、制裁方式与救济途径 | 经验观察、规则还原 |
| **AI 辅助编码工作坊** | 演示用 AI 辅助对材料做变量提取与主题编码，**当场核验、当场纠正** | 研究方法、可复现性 |

**共同要点**：每项活动都必须有"核验"环节。只有生成没有核验的活动，会强化而非纠正对 AI 的盲信。

## 三、期末作业：实证研究方法要求

### （一）研究类型与样本量（二选一，须说明选择理由）

- **定性研究**：不少于 50 个案例。可采用扎根理论、案例比较、过程追踪、内容分析等方法
- **定量研究**：不少于 100 个案例。可采用描述统计、回归分析、社会网络分析等方法

案例须为可核验的真实材料：公开文书、案例库、行政处罚决定、平台规则文本、访谈或参与观察记录等。

### （二）必须使用人工智能参与分析

**可以使用 AI 完成**：文献梳理、编码方案设计、变量提取与标注、主题归纳、文本清洗、统计分析代码生成与调试、语言打磨。

**必须遵守**：AI 输出的一切案例要素、编号、法条、数据与引文，**须逐条人工核验后方可写入论文**；禁止将未经核验的 AI 生成内容作为事实使用。

### （三）提交材料（六项，缺一不可）

1. **论文正文**：含引言、理论、材料、分析与讨论
2. **数据与材料附录**：案例清单（编号、来源、时间、关键变量、可核验的编号或链接）、编码手册、抽样与去重规则
3. **AI 对话记录**：完整原始导出（含时间戳与模型名称、版本），并按轮次标注用途
4. **AI 使用诀窍与反思报告**：提示词的设计与迭代；AI 在哪些环节有效、哪些失效；如何发现并纠正 AI 错误；判断"可信任/不可信任"的标准是什么
5. **数据分析代码**：可复现，关键步骤附注释；若由 AI 生成，须逐行理解并说明各段作用
6. **复现说明（README）**：数据来源与检索式、检索时间、样本筛选流程图、变量定义表

### （四）伦理与合规

- 不得向 AI 提交未公开的个人信息、涉密材料与当事人可识别信息；必要时先匿名化
- 遵守数据来源平台的使用条款与著作权规定
- 论文末尾须附「人工智能使用声明」，说明使用环节、模型名称与人工核验方式

### （五）评分标准（百分制，五项各 20 分）

| 项 | 内容 |
|---|---|
| a | 研究设计与问题意识 |
| b | 数据与代码质量 |
| c | 理论运用与分析深度 |
| d | **人工智能使用的规范性与反思质量** |
| e | 学术写作与规范 |

**凡发现未经核验的虚假案例或引文，按学术不端处理。**

---

## 四、案例汇报评分标准（百分制，五项各 20 分）

适用于学生的课堂案例讨论汇报。

| 项 | 内容 |
|---|---|
| a | 是否清楚地介绍了案例事实 |
| b | 是否清晰地界定了适用的规范 |
| c | 是否采用了理论视角进行分析 |
| d | 是否提出了独特视角，并引导或激发了有意义的讨论 |
| e | **是否引导同学识别自身回答与 AI 回答之间的差异，并发现 AI 回答中的错误或遗漏** |

**一致性要求**：汇报时长、字数要求、提交材料项数必须在**课件、大纲、各讲讲稿**中完全一致。这是最容易被学生发现的不一致点，交付前必须统一（见 `qa-rubric.md`）。

## 五、配套的警示案例

在第一次讲解 AI 使用规范时，宜给出真实后果案例（须核实后引用）：

- 有法律从业者因提交 AI 编造的引用而被法院处罚（说明"未核验"的真实代价）
- 公开的"AI 幻觉案例数据库"收录数量与分布（说明这是系统性问题，而非个人疏忽）
- 其中"专业人士本人"也会出现幻觉的比例（说明任何使用者都可能中招）

**教学要点**：把课程作业中的逐条核验要求，与学生未来职业中的核验义务直接挂钩——学生对该规则的认同度会显著提升。
